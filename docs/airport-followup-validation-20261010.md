# 공항 상단 화면·월별 국가 비교 후속 수정

기준 main: `70ec17577c7ff9fb4b4beffae21c647a9e05532e`. PR328은 사용자가 병합했고 자동 배포가 성공했다. 이 후속 브랜치는 별도 초안 PR이며 에이전트는 병합·배포·제공자 재수집을 실행하지 않았다.

## 동작과 분모

- 하단 중복 제목·도입·터미널 스위치·점프를 제거하고 상단의 실제 모형에 시간 기준·검색·전체 항공편·상세와 출처를 통합했다. 전역 전체/T1/T2/탑승동 선택, 출국/입국/항공편/시설/과거, 업종 가이드와 공식 지도 링크는 유지한다.
- 첫 화면은 하루 전체. 1/3/6시간과 직접 설정은 클릭으로만 선택한다. 선택 날짜·터미널이 바뀌면 하루 전체로 시작한다. 하루 전체 편수와 동/중앙/서/미정 편수는 선택 시간과 독립하며 모형의 수치·비율과 항공편 목록은 동일한 선택 시간을 쓴다. 익일 구간 자료가 없으면 확인된 부분만 표시하고 전체 비율을 만들지 않는다.
- 현재 날짜의 성공한 A1 확인 시각은 `source_health.last_retrieved_at`에 대응하는 summary source에서 읽는다. 원본 항공편의 마지막 변경 시각, 화면 API 조회 시각과 구분한다. 날짜/기기 시각을 움직여 수집 시각을 갱신하지 않는다. 일정 대체값에는 성공 수집 시각을 붙이지 않는다.
- 동서 명칭의 공식 위치 안내와 코리테일이 공식 지도 좌표로 계산한 탑승구 경계를 구분한다. 모든 게이트 구분을 공식 구역 지정이라고 주장하지 않는다. 공식 좌표 SVG는 명시적으로 펼칠 때만 생성한다. 보류된 동서 승객 추정을 복원하지 않았다.
- 월별 제목은 ‘국가별 항공편 · 전월 대비 일평균’. 실제 보유 원시 행을 한 번 순회해 국가×구역 교차 편수를 집계하고 각 월의 실제 포함 날짜 수로 나눈다. 국가·구역 주변 합계로 교차 비율을 추측하지 않는다. 전월 0/자료 없음의 신장률은 계산하지 않는다. 미정 위치·탑승동·미확인 국가도 전체 표에 남긴다. 편수는 승객 국적이나 사람 수가 아니다.
- 월별 버전2는 버전1의 유효한 포함 날짜 증거만 승계하고 이전 게이트 수치는 재사용하지 않는다. 기존 일일 Actions의 다음 정상 작업이 보유 원시 행으로 재계산한다. 새 DB 테이블·스케줄러·Worker 원시 스캔·원격 쓰기를 추가하지 않았다.
- 국가 국기는 기존 Blender WebP 4종과 검토된 SVG를 재사용한다. 두 작은 막대는 실제 일평균에 비례하는 정적 SVG이다. 새 Blender 생성물이라고 부르지 않는다.
- 서울 비교 문구는 실제 체류인구 추정 범위와 비교 관측 날짜·시각을 한 문장에 명시한다. 겹치지 않는 범위에서만 최소 사람 수 차이를 계산하고 숫자만 기존 굵기로 강조한다. 결제·업종·미래 예측의 비율을 만들지 않는다.
