# KORETAIL 앱 아이콘 연결 — Blender 비행기·활주로

기준 main은 `23ae0818cf172e7c28a137fe9831c0d9628549f1`(PR302 병합)이다. 이 변경은 앱 아이콘에 한정한다. 두 번 거절된 핵심 카드·헤더 변경과 PR266 링크 공유 이미지는 포함하지 않는다. 사용자 직접 병합 범위를 유지하며 이 문서만으로 공개 반영을 주장하지 않는다.

앱 아이콘 연결 호출은 첫 거절 후 한 번 재시도에서 허용됐다. 기존 53개 보호 파일을 유지하고 아이콘 관련 기존 7개 해시만 갱신했으며 새 경로 8개를 활성 보호에 추가했다. 총 61개 해시 검사와 기존 스케줄·이전 기록·검사 코드는 유지한다. 새 HEAD의 필수 CI와 검토용 PR로 인계하며 병합·운영 배포는 완료로 주장하지 않는다.

기존 `icon_flight_v2/flight-B.blend`를 실제 Blender 5.2.1 LTS에서 열어 모형·재질을 재사용했다. 이전 후보의 앱 아이콘 최종 승인을 가정하지 않고, 이번 구현 요청의 활주로·비행기·차분한 파스텔 방향에 맞춰 B 재질을 선택했다. 카메라 여백과 렌더 설정만 바꿔 Cycles CPU로 1024×1024 RGB PNG를 렌더했다. 긴 글자·새 명칭·AI 생성 이미지는 추가하지 않는다. 기존 검은 KORETAIL 워드마크와 앱명을 유지한다.

![실제 픽셀 크기와 마스킹 검토](../assets-src/app-icons-20261007/previews/app-icons-review.png)

favicon ICO에는 16·32·48px 프레임이 있고 SVG에는 같은 Blender 렌더의 128px PNG를 내장한다. Apple Touch는 180px, manifest의 일반 아이콘은 192·512px, maskable은 512px다. 원본 파일은 모서리를 미리 자르지 않은 전체 사각형·불투명 RGB이며 OS 형태는 미리보기에서만 적용했다. 모형 전체 정점의 투영 반경은 0.385이며 배경을 제외한 중요 조형을 중앙 0.4 반경 안에 두었다. 안전 영역 기준은 [W3C Manifest의 icon masks](https://www.w3.org/TR/appmanifest/#icon-masks), Apple 전용 링크는 [Apple Web Clip 문서](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html)를 참고했다. 이 미리보기 모양을 실제 OS의 정확한 마스크라고 주장하지 않는다.

새 메타데이터는 `-20261007` URL을 사용하고 루트 기존 이름도 같은 바이트의 호환 자산으로 제공한다. manifest의 `id=/`, 시작 주소 `/ko`, scope `/`, 이름 KORETAIL은 유지한다. 2026-10-07 05:51 UTC 공개 응답에서 이전 아이콘 `max-age=604800`, manifest `max-age=86400`과 기존 파란 블록 파일을 확인했다. URL 변경은 새 설치의 새 파일 요청을 분리하지만 기존 iPhone 홈 화면 아이콘이 즉시 자동 갱신한다고 보장하지 않는다. iPhone·Android 실기기 설치, OS 색조 모드와 기존 설치 캐시는 검증하지 않았다.

재현 가능한 원본은 `assets-src/app-icons-20261007/model/koretail-app-icon.blend`, 렌더 스크립트 `rerender-icon.py`, 축소·ICO·SVG·manifest 생성 스크립트 `export-icons.py`에 보존한다. Blender에서 `blender --background --python rerender-icon.py`, Pillow가 설치된 Python에서 `python export-icons.py`로 재생성할 수 있다. export 입력에는 같은 폴더의 `model/manifest-base.webmanifest`를 사용한다. 실제 출처·해시·카메라와 안전 영역 수치는 `checks/blender-provenance.json`에 있다.

검증은 변경 영향과 필수 CI에 한정한다. PNG 크기·불투명 배경·ICO 프레임·manifest 역할·새 URL/호환 파일 일치, 실제 브라우저 메타데이터·파일 응답, 원본 UI Lock의 나머지 해시·목록·스케줄 유지, 타입·린트·빌드·비밀정보 검사 결과를 PR에 기록한다. 검사 비활성화나 보호 목록 축소를 하지 않는다.
