## 변경 이유와 결과
직원에게 공유할 때 긴 근거 목록 대신 현재 선택한 날짜·장소·업종의 핵심 최대 3개와 구체적 준비 행동 최대 3개를 표시합니다. 미리보기·텍스트 복사·PNG·기기 공유는 동일한 문서를 사용합니다. 공식 행사 기간은 실제 행사 운영/혼잡으로 해석하지 않으며, 보류된 편수 기반 승객 배분 추정은 공유에 넣지 않습니다. 전체 화면의 원래 근거와 정보는 유지합니다.

공항 탑승구 출발편에는 기존 실제 집계에 연결한 작은 SVG 막대와 범례를 추가했습니다. 중앙·미확인 편수를 포함한 전체 분모와 동서 비중의 동+서 분모를 명시하고, 원래 숫자·전체 시간대 열람을 유지합니다. 새 3D 엔진, 이미지, 데이터 요청, 수집기 변경은 없습니다.
