## GA 숫자 구분과 테스트 방문 공개

- GA의 **이벤트 수**는 모든 이벤트를 셈. 첫 요청의 `_fv`/`_ss` 표시로 GA가 first_visit과 session_start를 따로 만듦. **조회수**는 page_view만 셈. **사용자**는 서로 다른 브라우저(client ID) 수임
- 한 번의 방문(위 흐름)은 다음처럼 집계됨:
  - page_view 6건 → 조회수 6
  - 이벤트 수 약 8 = page_view 6 + first_visit 1 + session_start 1
  - 사용자 1
  - user_engagement는 관찰되지 않음
- 이 작업으로 생긴 운영 방문은 run 2회 × 2개 기기 = 4회임
  - 모든 수집 요청을 중단했으므로 **GA에 전달된 이벤트·조회수·사용자는 0**
  - Google에는 gtag.js 다운로드만 발생했고, Cloudflare에는 일반 페이지 요청으로 집계될 수 있음
- 로컬 검증은 가짜 ID `G-TEST1234`와 대체 태그로 진행했으며 Google 전송은 0건. 일부러 고장 낸 대체 태그 두 가지(pushState 때 중복 page_view, 철회 무시)는 각각 R5와 R4 FAIL로 잡힘
- `deliver_test_hit=true`는 실행하지 않음
