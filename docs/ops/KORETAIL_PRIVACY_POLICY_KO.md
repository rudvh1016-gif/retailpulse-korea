# 코리테일 개인정보처리방침

> 출시 원고. 2026-11-23 KST에 운영자가 방침 확정 작업을 승인했다. 아래 본문은 계정 출시 후보에 구현된 처리 흐름을 기준으로 작성했다. 공개 운영자·권리행사 연락처와 운영 환경의 정보 처리 사실을 확인하기 전에는 게시하지 않는다. 예정 주소는 `/ko/privacy`다.

## 본문

### 이용 목적과 처리하는 정보

코리테일은 공항 정보를 회원가입 없이 제공합니다. Google로 계정을 연결하면 근무표, 업무 기록, 고객 안내 문구, 체크리스트, 알림 설정 등 이용자가 저장한 개인 도구를 같은 계정에서 이용할 수 있습니다.

| 처리 항목 | 사용하는 이유 | 보관과 삭제 |
| --- | --- | --- |
| Google 계정 식별자, 코리테일 계정 번호, 가입 시각 | 로그인한 사람의 계정과 자료를 올바르게 연결 | 서비스 계정이 유지되는 동안 보관하며 계정 삭제 시 운영 DB에서 삭제 |
| 이용자가 직접 저장한 근무 정보·메모·브리핑·안내 문구·체크리스트·알림 설정, 수정 이력 확인용 버전 값 | 이용자가 입력한 자료를 보관하고 여러 기기에서 같은 자료를 불러오기 | 개인 도구 자료 삭제 또는 계정 삭제 시 운영 DB의 기존 자료를 삭제 또는 교체 |
| 로그인 확인용 정보, 세션 확인값, 발급·만료 시각, 요청 횟수 제한용 집계 | 안전한 로그인 유지, 중복·과도 요청 제한 | 로그인 준비 정보의 유효기간은 10분, 로그인 세션은 최대 7일. 만료된 기록은 이후 로그인 처리 중 정리하며, 계정에 연결된 세션과 개인 요청 카운터는 계정 삭제 시 종료·삭제 |

Google 로그인 응답에 이메일이 포함될 수 있습니다. 코리테일은 응답의 서명과 계정 식별자를 확인해 로그인하며, 이메일이나 프로필 이름을 계정 자료에 저장하지 않습니다. Google 비밀번호를 받지 않으며, 연락처·Drive·캘린더 접근 권한을 요청하지 않습니다. Google의 로그인 화면에서 정보가 어떻게 처리되는지는 [Google 개인정보처리방침](https://policies.google.com/privacy)에서 확인할 수 있습니다.

브라우저에서 만든 기존 기기 자료는 계정에 자동으로 올라가지 않습니다. JSON 백업을 직접 복원하면 백업 전체 내용이 계정 저장을 위해 서버에 전송됩니다. 업무 메모나 백업에는 고객 이름·연락처, 결제 정보 등 다른 사람의 개인정보 또는 민감한 정보를 입력하지 마세요.

### 기기 저장, 쿠키와 알림

코리테일은 Google 로그인 연결과 로그인 상태 유지를 위해 만료되는 필수 쿠키를 사용합니다. 쿠키를 막으면 로그인 기능이 동작하지 않을 수 있습니다. 공항 정보는 로그인 없이 볼 수 있습니다.

계정 없이 쓴 기기 저장 기능은 브라우저에 정보를 보관합니다. 브라우저 설정에서 사이트 데이터를 지우면 기기 자료도 삭제될 수 있습니다. 출국장 알림은 이용자가 브라우저에 허용하고 계정 화면을 열어 둔 동안 제공됩니다. 브라우저 설정에서 알림 권한을 끌 수 있습니다.

### 내 정보 확인과 삭제

계정 화면에서 개인 도구 정보를 조회·수정하고 JSON 백업으로 받을 수 있습니다. 계정을 삭제하려면 Google로 다시 로그인하고 삭제를 확인하세요. 삭제하면 운영 DB의 계정과 연결된 개인 자료를 지우고 모든 기기의 코리테일 세션을 끝냅니다. 로그아웃은 현재 로그인 세션을 종료합니다.

이미 내려받은 파일이나 기기에 별도로 보관한 자료는 각 파일과 브라우저의 저장소에서 직접 관리할 수 있습니다. 코리테일 연결을 끊는 것과 코리테일에 저장한 계정을 지우는 것은 별도입니다. 코리테일 자료를 지우려면 코리테일 계정 화면에서 삭제를 완료하세요.

### 보호 조치

개인 도구 자료는 공항 자료와 분리된 계정 저장소에 암호화하여 보관합니다. 계정 확인과 접근 제한을 적용하고, 로그인 정보를 확인할 때 사용하는 세션 원문을 계정 DB에 저장하지 않습니다.

## 운영 확인 후 본문에 넣을 공개 항목

| 확인할 사실 | 공개 문구에 반영할 내용 |
| --- | --- |
| 실제 개인정보처리자와 공개 문의 채널 | 운영자 또는 담당부서의 공개 명칭과 작동하는 업무용 이메일 또는 문의 URL. 열람·정정·삭제·처리정지·피해 문의를 받는 창구 명시. 저장소·개인 프로필 연락처를 전용하지 않는다. |
| Cloudflare Workers·D1의 운영 계약 및 설정 | 실제 처리위탁자와 업무, 국외 처리·보관 해당 여부 및 해당 시 이전받는 곳·국가·항목·시점과 방법·목적·보유기간·거부 방법과 영향. D1 물리 보관 위치, 운영 로그 및 Time Travel 복구 데이터의 범위와 실제 보관·파기 기간도 확인한다. |
| 운영 환경의 통계·로그·문의 기능 | GA4 활성 여부와 실제 전송 항목 및 선택·거부 방법, 사이트 요청 로그와 보관 기간, 문의로 받은 정보와 보관 기간. 활성 기능과 실제 보관 조건을 확인해서만 기재한다. |
| 게시 시각과 버전 | 정책 시행일과 버전, 변경 공지 방법. 다른 권리 구제 창구와 만 14세 미만 이용 관련 조치가 적용되는지 운영 범위와 함께 확인한다. |

운영 점검 시 코드상의 10분·7일은 인증 유효기간으로 취급한다. 삭제 후 복구 기록이나 운영 로그가 언제 물리적으로 사라지는지는 별도의 운영 설정과 약관을 확인한다. 공개 문서는 한국어 홈과 계정 화면에서 링크하고 Google의 동의 화면에 같은 공개 HTTPS 주소를 등록한다.
