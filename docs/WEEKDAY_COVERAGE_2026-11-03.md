# 요일별 출발편 표본·누락 안내

## 원인과 운영 원자료 확인

2026-11-03 `/api/live/airport-days?date=2026-11-03` 응답을 정규화해 확인했다. 기준 2026-10-01~31은 31/31일, 비교 2026-11-01~02는 2/2일 완전 수집 상태다. 비교 기간은 일요일과 월요일만 포함한다. 월요일 1일의 공항 전체 합계는 545편, 일요일 1일은 551편이다. 화~토의 표본 0일은 수집 장애가 아니라 선택 기간에 해당 요일이 없기 때문이다. 종전 `4일 / 1일`은 두 기간의 평균에 사용한 표본 수였으며 날짜처럼 보였고, 없는 값은 하이픈으로만 보였다.

## 변경과 안전장치

- 요일별 달력상 예상 일수, 실제 유효 표본, 누락 날짜, 상태를 독립 계산한다. `not-in-range`, `missing`, `partial`, `complete`를 구분한다.
- 차트 표본을 기준/비교 두 줄로 표시한다. 상세 표는 `표본 N일 · 기간 내 M일`과 없는 이유를 표시한다. 일부 미수집이면 유효 표본 평균임을 알린다.
- 선택 기간에 해당 요일이 없으면 `선택 기간에 해당 요일 없음`, 날짜는 있지만 정상 완료 기록이 없으면 `완료 수집 자료 없음`으로 표시한다. 원인을 확정할 수 없는 미수집을 API 장애로 단정하지 않는다.
- 누락을 0으로 채우지 않는다. 정상 완료 0편 기록은 그대로 유지한다. 불완전·중복·합계 불일치 기록은 기존 정규화 검증으로 제외한다. 한쪽 또는 양쪽 기간이 비어도 요일별 이유를 볼 수 있다.
- API 실패 시 기존 불러오기 실패·재시도 동작을 유지한다. 이전 기록을 현재 값으로 대입하지 않는다. 다른 차트의 계산과 기존 삼각형 수정은 유지한다.
- 영어·중국어 안내도 제공하며 생성 자산과 캐시 버전을 함께 갱신한다.

## 검증

`tests/airport-weekday-coverage.test.mjs`: 월초, 기간에 없는 요일, 실제 수집 누락, 일부 표본, 정상 0편, 빈 자료, 불완전·중복·손상 기록.

`e2e/airport-weekday-coverage.spec.ts`: 390/1440px에서 문구·표본·키보드 선택·넘침 검사와 화면 캡처, 불완전 자료, 503 오류 안내. 기존 기간 분석 브라우저 회귀 검사도 수행한다. PR의 최종 CI 및 배포 증거를 확인한다.
