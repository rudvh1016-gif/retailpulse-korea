## 실제 저장한 것

`lib/prepared-areas/itaewon.ts`에 기존 `AreaMapping`의 자료형을 재사용하는 준비 데이터를 저장했다. 실제 지역표(`lib/areas.ts`)는 이 파일을 가져오지 않는다. 새로운 활성화 플래그·API·서버·유료 의존성은 없다.

현재 `allAreaIds = Object.keys(areaMappings)`이며 여러 수집기가 이를 순회한다. 따라서 곧바로 지역표에 넣으면 수집량을 늘리는 부작용이 있다. 이번 PR은 이 연결을 하지 않는다. 메뉴·개인 설정·공개 route·sitemap·예측 허용 지역은 기존 세 지역 그대로다.

- 오너가 실제 공개 범위를 승인한 뒤 기존 서울 도시데이터·생활인구·추정매출·날씨 공급 구조에 하나씩 연결한다. 새 키 발급 없이 기존 키를 쓴다.

- 네 언어 표시·공개 주소·canonical/hreflang/sitemap·개인 설정은 데이터 준비 확인 후 함께 검토한다. 준비 PR을 병합하는 것만으로 이태원이 나타나지 않는다.

이 PR은 준비 데이터 보존 완료이며, 실서비스 수집·공개 활성화 완료라는 뜻이 아니다.
