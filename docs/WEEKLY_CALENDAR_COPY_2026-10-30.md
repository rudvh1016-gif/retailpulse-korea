# 이번 주 공식 일정 — 국가별 구분과 보조 설명 축약

사용자가 제공한 `IMG_1723.png`를 직접 확인했다. 공항현황의 ‘이번 주 공식 일정’에서 미얀마·카자흐스탄 항목이 붙어 보이고, 이미 위에 표시한 종료일과 검토일이 회색 줄에서 반복되는 문제였다.

- 국가별 이름·실제 시작/종료일은 유지하고 항목 사이에 16px 간격을 둔다. 하루짜리는 같은 날짜를 두 번 표시하지 않는다.
- 반복 종료 상태 설명을 제거한다. 대상 범위·공식 확인일·원문 링크는 기본 닫힌 ‘적용 대상·공식 출처’에 보존한다. 휴일의 출입국 집중·국적·매출 예측 금지 문구와 전체 일정 이동은 유지한다.
- 모바일(700px 이하)의 회색 보조문은 12px에서 11px로만 줄이고, PC 보조문 12px와 국가명·날짜 본문 14px는 유지한다.
- 데이터, 대표 일정 선정, 순서, 주간 경계, 검토일, 폰트 가족·본문·PC 크기·굵기·색, 수집기·API·DB·비용은 변경하지 않는다.
- 기반 main `0f4c87efd91521c05b42aa2ebc0b5da19689df07`는 #517과 #518을 포함한다. 이후 다른 PR이 main을 바꾸면 해당 diff를 재확인한다. #520의 OverviewHeadline 및 .focus-week-comparison 선택자와 함수·CSS 범위가 겹치지 않는 것을 담당자에게 확인했다.
- 한국어·중국어 단위 회귀와 320/390/1440 브라우저 회귀를 추가한다. 브라우저는 기본 닫힘·키보드 열기/닫기·원문/대상 보존·항목 간격·가로 넘침·전체 일정 이동을 확인한다.

실제 검사 결과와 게시·CI·병합·배포 상태는 이 변경의 PR에서 별도로 구분한다. 운영 반영을 확인하기 전에는 배포 완료라고 부르지 않는다.
