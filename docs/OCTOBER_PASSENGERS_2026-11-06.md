## 공식 자료와 운영 데이터

- [인천공항 지역별 공식 통계](https://www.airport.kr/co_ko/651/subview.do)의 실제 조회 경로 `https://www.airport.kr/fsmFsn/co_ko/statisticCategoryOfLocal.do`에서 2026년 9월과 10월을 각각 조회했다. `nvgSe`, `arplnSe`, `pas`, `bag`, `terminalId`, `areaSe`는 모두 빈 값이며 각 요청의 시작·종료 월은 동일하다. 확인일 2026-11-06.
- 국가는 승객 국적이 아닌 상대 공항의 국가이다. 터미널 분할 없는 공항 전체 출발 여객 실적이다. 지역별 표의 합계 행과 국가 행을 중복 합산하지 않았다.
- 기존 [One-shot Data Import 42173616962](https://github.com/rudvh1016-gif/retailpulse-korea/actions/runs/42173616962)를 main에서 `sources=airport_monthly_stats`, `confirm=IMPORT`로 실행했다. **SUCCESS**, 제공자 요청 2회, 변경 행 2건(국가별 10월 1건·시간대별 10월 1건), 보존 구간 2025-10~2026-10. 기존 changed-only 수집기·정규화·D1·공개 읽기 경로를 그대로 사용했다.
- [운영 정확 월 비교 API](https://koretaildata.com/api/live/airport-passenger-comparison?selected=2026-10&baseline=2026-09)는 READY, 9월 59개·10월 58개 비집계 국가 행이다. 공식 HTML의 모든 국가 행에서 도착·출발·합계가 운영 API와 일치했다. 각 월 국가 행의 출발 합도 공식 지역별 표 합계와 일치한다.

## 공지와 최소 변경

기존 한국어 공지의 첫 항목으로 공식 공개·반영, 주요 국가 변화, 일수 보정, 국가 정의, 출처와 확인일을 추가한다. 기존 브리핑·쇼핑 공지를 보존한다. 한국어 공지 날짜만 11월 6일로 갱신한다. 새 공지 버전으로 이전 공지의 숨김 설정을 구분하며 다른 설정은 유지한다. `new update!` 제목과 이번 10월 항목 제목만 버건디 `#800020`으로 표시한다. 강제 색상 모드에서는 시스템 글자색을 사용한다. 국가별 실적 링크는 `/ko/airport-countries?mode=passengers#airport-route-passengers`이다. 더보기의 '공지사항 보기'에서도 다시 열 수 있다.

스키마·색상 체계·기존 통계 계산·수집 코드·주기·키·권한·유료 서비스는 변경하지 않는다. 기존 수집 경로를 통한 저장 2행 외 새로운 지속 쓰기가 없으므로 아키텍처 변경용 30항목·트래픽 모델을 새로 주장하지 않는다. 기존 단위·스케줄·누락·changed-only·보안 검사와 UI 회귀를 검증하고, 정확한 최종 CI·병합·운영 SHA와 운영 화면 결과는 PR에 기록한다.

- Windows vinext start는 빌드 자산을 404로 제공해 최초 브라우저 시도는 제품 검증에 사용할 수 없었다. 저장소 밖 로컬 프록시가 동일한 `dist/client`/`public` 바이트를 제공하도록 분리했다. 실제 배포 서버 경로의 전체 브라우저 검증은 Linux PR CI를 필수로 한다. 분석 opt-out과 Google tag 차단을 유지한다.
