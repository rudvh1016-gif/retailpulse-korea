# KORETAIL 업종별 운영 안내 고도화

기준: origin/main `ac06c78` (2026-09-21 확인). 오너 요청: 최신 작업을 확인하고 필수 정보를 한 번에 제공하며, 특히 공항과 화장품 등 업종별 제안을 구체화한다.

## 결정

문구만 늘리는 방식보다, 기존 공식 요약 뒤에 업종별 실행 안내를 연결한다. 새 데이터 수집이나 판매 예측은 추가하지 않는다. 흰 배경, 기존 글꼴·크기 토큰, 얇은 구분선, 텍스트 선택 메뉴를 재사용한다.

- 첫 방문: 검토한 PR #202의 공개 요약 우선 동작과 회귀 검사를 통합한다. 저장된 개인 설정은 유지한다. #201의 동적 문구는 이번 범위에 포함하지 않는다.
- 매장: 여섯 업종 모두 핵심 판단, 실행 방법, 마감 때 기록할 항목을 제공한다. 기본 화장품 안내는 색상·용량, 테스터, 상담·결제 분담, 품절 기록을 명시한다.
- 공항: 출국 일반구역 / 출국 면세구역 / 입국 일반구역 / 입국 면세구역 / 탑승동의 위치별 확인 사항과 업종별 추가 지침을 제공한다. 위치 선택은 이용자의 선택이며 실제 매장 위치를 추정하지 않는다.
- 근거 경계: 공항 예보와 매장 유입, 항공사와 고객 국적, 외국인 생활인구와 구매·응대 언어를 구별한다. 일반 가이드는 과거 날짜에서도 실측 결과처럼 보이지 않도록 상시 운영 참고로 명시한다.
- 접근성: 업종 선택은 일반 버튼의 aria-pressed, 위치는 label이 있는 select, 자세한 내용은 native details. 새 가이드는 API나 저장 요청을 만들지 않는다.

## 검증

실제 브라우저에서 첫 방문/취소/재방문, 여섯 업종 전환, 공항 출국/입국 기본 위치, 위치 변경, 네 언어, 모바일 넘침, 자료 누락을 확인한다. 기존 전체 단위검사·렌더 검사·빌드·lint·typecheck·secret scan과 CI를 수행한다.
