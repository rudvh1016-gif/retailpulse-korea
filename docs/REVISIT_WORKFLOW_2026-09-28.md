## 3. 7단계 — 재방문·업무 사용 측정 정의

### 3.1 도구 상태 (구분해서 적음)

| 도구 | 코드 존재 | 활성화 | 이벤트 수신 | 통계 확인 |
|---|---|---|---|---|
| GA4 (`lib/personal-analytics.ts`) | 있음 | 배포 기록상 ID·활성화 값 등록(2026-09-08, `PERSONAL_BRIEFING_OPERATIONS.md`) | **미확인** | **미확인** |
| Cloudflare Web Analytics | 대시보드 설정 | 운영 시각 검사에서 `/cdn-cgi/rum` 전송 확인 | 방문 집계만(사용자 식별 없음) | 대시보드에서 소유자 확인 필요 |

- GA4 이벤트는 사용자가 개인 설정에서 분석에 동의한 뒤에만 보내집니다(기본값 꺼짐).
- 그래서 아래 지표는 **동의한 사용자만**의 값입니다. 전체 방문자로 확대해 해석하지 않습니다.

### 3.2 이번에 추가한 이벤트 (결과가 확인된 순간에만)

| 이벤트 | 보내는 때 | 보내지 않는 때 | 같이 보내는 값 |
|---|---|---|---|
| `business_prep_viewed` | 자료가 있는 준비 브리핑이 표시됨 (날짜·장소·언어·판정 조합당 1회) | 로딩 중, 오류, 같은 조합 반복 | 언어, 장소(지역 id 또는 airport), 날짜 관계(오늘·내일·어제), 판정 |
| `business_prep_copied` | 클립보드 복사 성공 | 버튼만 누르고 실패 | 언어, 장소, 날짜 관계 |
| `business_prep_image_created` | PNG를 만들고 다운로드를 시작함 | 생성 실패 | 같음 |
| `business_prep_share_target_chosen` | 공유 창에서 대상을 고름 | 취소, 실패 | 같음 |
| `business_hours_saved` | 조건 저장 | — | 언어, 장소 (영업시간 값은 보내지 않음) |
| `business_feeling_recorded` | 체감 기록 저장 | 저장소 차단 | 언어, 장소, 날짜 관계(오늘) (체감 값은 보내지 않음) |

- 이벤트 이름을 결과에 맞춘 이유가 있습니다. 화면 표시를 유효 조회로 보지 않고, 버튼 클릭을 복사 성공으로 보지 않기 위해서입니다. 공유 창 열기를 전달 완료로, PNG 생성을 상대가 봤다는 뜻으로 보지 않기 위해서이기도 합니다.
- 허용 목록 방식과 값 제한(`safeAnalyticsParams`)은 그대로입니다.
  - 매장명, 회사명, 영업시간, 메모, URL 검색어는 보내지 않습니다.
  - 새 사용자 식별자, 브라우저 지문, 기기 간 추적은 없습니다.

### 3.3 지표

| 지표 | 분자 | 분모 | 기간 | 범위·주의 |
|---|---|---|---|---|

- 확인 위치: GA4 탐색(Explorations)에서 이벤트 이름 기준으로 봅니다. 새 대시보드는 만들지 않았습니다.

## 4. 8단계 — 콘텐츠 초안 (발행하지 않음)

아래는 초안입니다. 네이버 블로그, 클립, SNS에 올리지 않았고 누구에게도 보내지 않았습니다. 같은 틀로 대량 생성하거나 복제 페이지를 만들지 않습니다.

### 초안 A — 명동 매장, 주말 전에 확인할 공식 자료 세 가지
- 대상: 명동 화장품·패션 매장 점장
- 요지:
  1. 서울시 실시간 도시데이터의 혼잡 공식 예측으로, 영업시간 안에서 '약간 붐빔' 이상인 시간을 먼저 봅니다.
  2. 기상청 단기예보에서 강수확률 50% 이상 시간이 있는지 확인합니다.
  3. 한국관광공사 행사 정보로 근처 공식 행사 기간을 확인합니다.
- 연결: `koretaildata.com/ko/business` (명동)
- 쓰지 않는 표현: 매출 증가 예상, 방문객 수 예측, 외국인 매출

### 초안 B — 중국 국경절 연휴(10/1~10/7) 전에 매장이 확인할 것
- 대상: 명동·홍대·면세 매장
- 요지:
  - 중국 국무원 공지(国办发明电〔2025〕7号)의 공식 연휴 기간은 10월 1일~7일입니다.
  - 9월 20일과 10월 10일은 중국의 조정 근무일이며 휴일이 아닙니다.
  - 이 시기에는 중국어 안내와 결제 수단을 미리 점검합니다.
- 쓰지 않는 표현: "중국인 관광객이 몰려온다"처럼 원인과 결과를 단정하는 문장
- 출처: gov.cn 공지 링크

### 초안 C — 비 오는 날 매장 준비, 무엇을 보면 되나
- 대상: 모든 업종
- 요지:
  - 기상청 강수확률은 시간대별로 발표됩니다.
  - 영업시간 안에 50% 이상인 시간이 있으면 우산 보관대와 입구 바닥을 준비합니다.
  - 발표 시각이 오래된 예보는 쓰지 않습니다.
- 쓰지 않는 표현: 비 때문에 매출이 줄어든다

### 초안 D — 인천공항 매장, 출국 예상 승객이 가장 많은 시간을 읽는 법
- 대상: T1·T2 매장 직원
- 요지:
  - 인천공항 공식 출국 예상(A5)은 시간대별 예고입니다.
  - 영업시간 안에서 가장 많은 시간대 전에 계산대와 재고를 준비합니다.
  - 합계는 모든 시간대가 발표된 경우에만 봅니다.
- 쓰지 않는 표현: 매장 방문객 수, 항공사로 추정한 승객 국적

### SEO 보존
- 바뀌는 페이지는 `/{lang}/business` 한 곳입니다.
  - 새 준비 브리핑은 브라우저에서 그려지고, 서버 렌더 HTML·canonical·sitemap·robots·공유 미리보기는 바꾸지 않았습니다.
- 배포 뒤 기존 `check:discoverability`(Discoverability 워크플로)로 회귀만 확인합니다. 전체 SEO 재수행은 하지 않습니다.

## 6. 8단계 — 확장 조건

### 지역 확장 (한 번에 한 지역, 승인 없이 정기 수집 시작 안 함)
1. 서울시 실시간 도시데이터 POI 코드, 상권(추정매출·점포) 코드, 대표역, 행정동, 기상청 격자, TourAPI 기준점을 **실제 공급원 응답으로** 확인합니다.
   - 이태원 때와 같은 읽기 전용 점검을 거칩니다(`docs/ITAEWON_PREPARATION.md`).
2. 저장 영향을 먼저 계산합니다.
   - 현재 구조로는 지역 하나당 하루 약 0.7MB, 쓰기 약 4~5천 행입니다(`docs/STORAGE_RETENTION.md` §5).
   - 보관 제안 1이 적용되면 이보다 크게 줄어듭니다.
3. D1 여유가 70% 미만이고 쓰기가 NOTICE 미만일 때만 제안합니다.
4. 범용 지역 확장 틀을 새로 만들지 않고, 이태원과 같은 방식으로 한 지역씩 추가합니다.

### 자료 확장
- 새 공급원을 추가하려면 다음을 모두 기록해야 합니다.
  - 계약(응답 형식)과 발표 시각
  - 호출 한도와 오류 형태
  - 이용 조건
