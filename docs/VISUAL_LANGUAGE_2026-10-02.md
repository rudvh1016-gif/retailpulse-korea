# 시각 규칙 — 공항 우선 (2026-10-02)

소유자 결정(2026-10-02): **공항을 앞세운다. 서울 4개 지역은 유지하되 뒤로 보낸다. 색은 파스텔(노을 하늘) 감성으로.**
이 문서는 그 결정을 화면 규칙으로 옮긴 것이고, 이후 모든 공항 화면 PR은 이 규칙을 따른다.

## 1. 선후 관계와 지켜지는 것

- 2026-09-03 "흰 바탕·따뜻한 색 금지"(docs/DESIGN_AUDIT_2026-09-03.md)는 **페이지 바탕과 본문**에는 그대로다. 페이지는 종이 흰색, 글은 먹색.
- 파스텔은 **공항 그림(figure) 안**에서만 쓴다: 자료 표시(막대·호·실루엣), 그림 바탕(haze), 움직임. 사이트 전체를 물들이지 않는다.
- "공항 전용 사이트 금지"(2026-09-30 지침)는 "공항 우선, 서울 유지"로 바뀐다. 서울 페이지·수집·데이터는 지우지 않는다.
- NEXT_PUBLIC_AIRPORT_HALL_SIDES OFF, 공지 게시 보류, 예측 모델 없음은 그대로.

## 2. 색 (app/airport-visual.css)

소유자가 준 참고 프레임(노을 하늘 위 구름)에서 뽑았다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--sky-100/200/300/500` | #eef3fa · #d7e3f3 · #afc7e8 · #7fa3d1 | 하늘. 중앙·보조 표시, 연한 바탕 |
| `--dusk`, `--dusk-deep` | #4b6b9e · #334d78 | **동편**. 공항 그림의 강조색 |
| `--cloud-100/200/400/600` | #fbf1e8 · #f6d3bb · #efb38f · #d98a63 | **서편**. 따뜻한 대비색 |
| `--haze` | #fbf7f2 | 그림 바탕. 페이지 바탕에는 쓰지 않는다 |
| `--slate` | #3f4a5c | 파스텔 위의 글자·현재 시각 선 |

규칙: 그라데이션·그림자 금지. 한 그림에 동(dusk)·서(cloud)·중앙(sky)·미확인(빗금) 네 가지만. 사이트 공통 `--blue`(#214cff)는 그림 안에서 쓰지 않는다(파스텔과 충돌).

## 3. 글자

- 큰 숫자 하나(`.av-display`, 40~72px, 고정폭 숫자) + 작은 설명 한 줄. 숫자 옆 단위는 작게.
- 제목은 지금처럼 눈썹(eyebrow) 대문자 + 문장형 제목. 새 글꼴을 추가하지 않는다(글꼴 서브셋 시험이 막는다).
- 설명은 한 문장. "~입니다"로 끝나는 안내문을 두 줄 넘게 쌓지 않는다.

## 4. 움직임 (lib/motion.ts, GSAP 3.15 Standard no-charge licence)

- 움직임은 **자료가 들어오는 과정**을 보여줄 때만: 숫자 카운트업, 막대·호·선이 자라남, 하루 재생. 장식용 움직임·반복 움직임·배경 움직임 금지.
- 한 번만, 0.56초(reveal) 또는 0.24초(state), ease-out. 등장 순서는 읽는 순서.
- GSAP은 그림이 처음 움직일 때만 불러온다(동적 import). 첫 화면 JS에 포함되지 않는다 — `tests/visual-foundation.test.mjs`가 정적 import를 막는다.
- `prefers-reduced-motion`이면 최종 상태를 바로 그린다.

## 5. "AI 사이트 티"를 피하는 규칙

금지: 보라·파랑 그라데이션, 둥근 카드 빽빽, 이모지 아이콘, 스톡 일러스트, 좌우 대칭 영웅 이미지, 차트 라이브러리 기본 모양·기본 색, 설명문 과다, 반짝이·떠다니는 배경.
대신: 자료 밀도, 여백, 한 가지 강조색, 직접 그린 선 아이콘, 목적이 있는 움직임.
마지막 판정은 사람(소유자)이 한다: 화면 하나 → 스크린샷 → 판정 → 다음.

## 6. 무게 예산

- 첫 화면 JS(gzip) 348KB 기준 +0. 그림·움직임 코드는 모두 지연 로드.
- GSAP 코어 약 23KB gzip, 공항 그림이 처음 움직일 때 1회.
- 새 요청·새 수집·새 D1 쓰기 없음. 자료는 이미 있는 summary/flights/airport-days만.
