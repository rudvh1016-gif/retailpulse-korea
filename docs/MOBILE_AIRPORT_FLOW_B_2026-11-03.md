# 모바일 주목할 공항 흐름 — 선택안 B

사용자가 선택한 B 이미지(`libfile_3d4ac260a6d08191ab54cbbdfe1930d2`, koretail-b.png)를 브라우저로 시각 확인했다. 사용자는 환율 영역은 기존 그대로 유지하고 모바일 영역만 적용하도록 요청했다.

## 적용

- 폭 700px 이하의 `glance-insights[aria-labelledby="airport-staff-briefing-title"]`에만 새 스타일을 적용한다. 701px 이상은 기존 PC 스타일을 유지한다.
- 현재 출국장 대기만 짙은 파란 배경으로 강조한다. 실제 대기 수치·단위·출국장 위치를 나눠 수치는 크게, 위치·관측 시각은 보조 정보로 보여 준다. 60분 이상 표기를 보존한다.
- 출발편 집중 시간, 목적지 변화, 시간·터미널, 노선·휴일 준비는 투명 배경과 짧은 파란 세로선, 여백으로 구분한다. 수치와 제목·기준 정보를 다른 크기로 표시한다.
- 기존 DOM 읽기 순서, 시각, 자료 없음 안내, 링크, 계산과 데이터 요청을 유지한다. 시안의 값은 제품에 넣지 않았다. 수치 분리는 기존 원자료에 대한 마크업 변경이다.
- 상단 환율·헤더의 코드와 스타일은 변경하지 않았다. 새 스타일의 모든 선택자는 해당 공항 흐름 그룹 내부로 제한했다. 기존 PC의 값은 인라인 표시와 구분점을 유지한다.
- 새 자동 재생 애니메이션이나 의존성, 수집·저장·배포 구조 변경이 없다. 포커스와 고대비 모드의 카드/세로선 처리를 포함한다.
- 모바일에서 시각적으로 생략한 위치·대기값/시간·편수 구분점은 화면 낭독기에 유지한다. 기존 PC의 인라인 구분점은 그대로 표시한다. 최종 접근성 검사 9건이 통과했다.

## 검증

- 전체 단위 검사 2,747건 통과.
- 관련 공통/환율/PC/다국어 브라우저 검사 37건 통과.
- 공항 한눈에 및 새 B안 브라우저 검사 53건 통과. 신규 B안은 320/390/430/700/701/1440px, 60+, 기존 0분 대표 제외 정책, 오래된 관측 제외, 링크·포커스·넘침을 확인한다.
- 변경한 공항 흐름 제목에 한해 기존 색·동일 들여쓰기·장식 제거 기대값을 B안으로 갱신했다. 다른 화면과 PC의 기존 기대값은 유지한다. 관련 제목 검사 21건과 부하 중 시간 초과된 다른 화면 3건 재검증이 통과했다.
- TypeScript, ESLint(기존 이미지 경고 2건, 오류 0건), 전체 빌드를 확인한다. 최종 PR/main CI 및 운영 배포 결과는 PR에 기록한다.
- 운영 변경 전 320/390/430/701/1440px 화면·헤더와 환율·PC 스타일을 저장했다. 배포 후 동일 폭에서 원자료·관측 시각·링크·스타일·넘침을 실제 화면과 대조한다.
