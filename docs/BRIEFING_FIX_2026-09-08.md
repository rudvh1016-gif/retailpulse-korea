운영 읽기 확인: 2026-09-08 요약의 T2 출발 기록은 249편이며 항공사 순위도 존재한다. 2026-09-09 요약에는 예상 출국객 39,174명이 있지만 A1 당일 운항 기록과 그 기반 항공사 순위가 없다. 별도의 A3 등록 일정은 있으나 개인 브리핑이 읽지 않았다. 기존 A3 요약은 유효기간만 검사하고 요일을 검사하지 않아 그 수치를 내일 전체 운항편으로 사용할 수 없다.

수정: 기존 A3 읽기 한 회를 최대 2,001개 행의 제한 조회로 바꾸고 유효기간·요일을 검사한다. 운항편명·시간·터미널로 중복을 제거하며 최대 2,000개만 요약한다. 실제 운항 자료가 없는 오늘/미래 날짜에만 등록 일정을 보조로 표시한다. 과거 실적을 현재 계절 일정으로 메우지 않는다. 미분류 일정은 T1/T2/탑승동으로 추측하지 않는다. 면세점 연계 일부 일정이며 전체 운항편이나 실적이 아님을 명시한다. 항공사 등록 국가는 승객 국적이 아니다.

항공사 상위 3개에 편수·비중을 추가하고 피크 시간의 예상 인원도 표시한다. 하단 내 브리핑 링크는 저장된 설정으로 홈에 복귀하며 홈에서 서울 메뉴가 잘못 활성화되는 문제도 수정한다. 브리핑 제목/수치/설명을 rem 기반 크기로 통일하고 작은 휴대폰에서 1열로 표시한다. 기존 완전한 Pretendard 글꼴을 사용한다. fontTools cmap 확인 결과 기존 글꼴에도 현재 한국어 문구 누락은 없었다.

검증: 기본 검사 622개 통과, 관련 데이터 검사 57개 통과, typecheck/lint/secret scan/build 통과. 모바일 재진입 자동 검사를 추가하고 기존 메뉴 개수 기대값을 6개로 수정했다. 브라우저 실행 결과는 CI 완료 후 확인한다.

운영 부담: 새로운 외부 API·수집기·일정·D1 쓰기·유료 서비스 없음. 기존 한 묶음 읽기 유지, 정렬·선택 결과 최대 2,001행. 실제 운영 CPU/무료 한도 여유는 별도 실측하지 않았다. 이 작업은 구조 변경이 아니므로 대규모 아키텍처 감사 표/트래픽 모델은 해당하지 않는다.
