# 도착국 면세한도: 무료 일일 확인과 제한적 자동 갱신

## 실제 범위와 공개 경계

이 변경은 기존 `Collect Production Data`의 하루 한 번 이벤트(06:07 KST)에
독립 `customs-allowance-check` 작업을 연결한다. 새 Cron·새 키·유료 API·AI 호출은 없다.
배포와 `0028` migration, 실제 첫 실행 확인 전에는 자동 운영 완료가 아니다.
GitHub 지연·실패 시 최신으로 가장하지 않고 화면에 대기/지연/실패 상태를 보여준다.

12개 국가·지역 모두의 마지막 검토 데이터는 유지한다. 60개 출처를 매일 모두
조회하지 않는다. 국가별 핵심 후보 12개 중 반복 읽기와 원문 bytes 검증이 된
일본·대만·싱가포르 3개만 자동 HTTP 확인 대상으로 승인했다. 나머지 9개는
`ACCESS_REVIEW_REQUIRED`로 남기며 자동 확인 성공이나 최신성으로 표시하지 않는다.

- 일본: `robots.txt`의 전체 허용, 공식 이용규약을 확인했고 실제 Shift_JIS 문서를
  검토했다. 인코딩은 해당 출처에만 명시적으로 허용한다.
- 대만: robots의 `LawAll.aspx` 허용을 확인했다. ASP.NET 세션값 때문에 전체 bytes는
  변하지만 법명·개정일·첨부 링크·전체 조문을 포함하는 정확한 법령 블록은 동일함을
  실제 두 차례 요청으로 확인했다. 그 블록의 변경도 빠짐없이 검토대기로 남긴다.
- 싱가포르: robots 허용, 원문 bytes와 내용 확인. 원문 재배포 없이 해시·관측 상태만
  저장한다. 이용규약이 상업적 원문 복제를 허용한다는 뜻은 아니다.
- 미국 eCFR HTML은 프로그램 접근을 개발자 API로 제한하므로 자동 HTML 수집하지 않는다.
- 필리핀 403, 호주 1MiB 초과 응답, 기타 출처 접근 검토 미완료는 우회하지 않는다.

## 일본 수치 자동 갱신

일본 주류 병 수/기준 용량, 궐련만의 수량, 향수 온스는 좁게 자동 갱신한다.
공식 원문의 검토된 전체 본문에서 정확한 네 숫자 셀만 자리표시자로 바꾼 뒤,
나머지 모든 조건·연령·날짜·예외·링크·구조가 승인 해시와 동일할 때만 허용한다.
제로·범위 초과·새 단위·신규 조건·시행일 문구·구조 변경은 즉시 검토대기다.
일반물품 20만 엔, 혼합/가열담배, 법률 해석은 자동 추정하지 않는다.

승인된 한국어 안내 데이터의 의미 해시에도 묶는다. 수동 검토 데이터가 바뀌면
이전 자동 수치가 새 조건에 덮어씌워지지 않는다. 공개 수치는 별도 1행에 저장하고
동일 수치를 다시 받으면 canonical 수치 쓰기는 0이다. 실제 변경 시에만 이전값과
변경 확인시각을 보존해 면세한도 패널에 `[공지]`를 표시한다. 최초 동일값 등록은
규정변경 공지가 아니다. 확인일을 시행일로 사용하지 않으며 시행일은 미확인으로 둔다.

이것은 12개국 모든 법률을 무인 해석·수정하는 기능이 아니다. 일본의 검증 가능한
숫자만 자동 갱신하고 다른 변경은 마지막 검토값을 유지하는 제한적 자동화다.

## 보존·비용·실패 처리

- 출처 현재 관측 최대24행과 일본 수치1행만 보관. 원문 HTML/PDF 무한 보관 없음.
- 출처당 24시간 due guard, 한 번만 읽기. 최대24요청/실행, 각1MiB/15초.
  현재 실제 대상은3개로 최악3요청/일. 기타9개는 요청 없이 차단 상태만 기록.
- 일일 관측 상태 쓰기 최대12행, 수치 변경 시 최대1행 추가. 매번 동일 법률 데이터
  덮어쓰기 없음. 반복 실행은 due 이전 provider 요청0/쓰기0.
- CAS가 오래된 실행의 새 결과 덮어쓰기를 차단한다. 오류는 마지막 수치를 보존한다.
- 방문자 API는 인덱스/상한이 있는 저장값 SELECT만 수행하고 5분 캐시한다.
  방문자 수집·API 키·AI 호출 없음.
- 비용 수치는 내부 상한 모델이다. Cloudflare 계정 전체 무료 잔량이 충분하다는
  실측 주장은 하지 않는다. 무료 한도 실패 시 유료 전환 대신 unavailable 처리.

## 검증

`tests/customs-allowance-check.test.mjs`, `tests/customs-allowance-runtime.test.mjs`,
`tests/customs-japan-numeric.test.mjs`에서 형식/단위/조건 변경, 실패 보존, due 중복,
SQLite migration/CAS, 수치 변경 공지, 새 수동 검토와의 충돌 차단을 검사한다.
실제 JP/TW/SG HTTP 요청 및 원문 검토를 수행했고, 원격 D1/실제 schedule 성공은
배포 후 별도 확인 대상이다. fixture 통과만으로 운영 성공이라 하지 않는다.

## 남은 과제

나머지9개 핵심 출처 접근 검토/공식 API 선정, 법률 조건 전체에 대한 국가별 안전
파서, 일반 공지판과의 연계는 미완료다. 현재 수치 변경 공지는 도착국 면세 패널에만
표시된다. 첫 운영 실행과 실제 공개 API 응답을 확인한 뒤 운영 상태를 보고한다.
