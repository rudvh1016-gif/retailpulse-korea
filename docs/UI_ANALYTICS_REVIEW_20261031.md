## 검색 노출 조사

운영 `/robots.txt`, `/sitemap.xml`, `/ko`, `/ko/airport-prepare`는 HTTP 200이었다. 홈과 준비 페이지 canonical은 각 정식 HTTPS URL이었다. 공개 robots는 페이지와 기존 읽기 전용 콘텐츠 API를 허용한다. 초기 HTML은 정식 서비스 화면 구조를 포함하지만 주요 수치는 아직 ‘확인 중’과 ‘—’로 나타난다. 이를 임의의 정적 수치로 채우지 않았다. 현재 홈 메타 설명에는 뷰티·화장품 업종 나열이 없으며 과거 검색 설명의 잔존 또는 검색엔진 선택 여부는 관리자 증빙 없이는 확정하지 않는다.

네이버 공식 가이드는 대표 URL의 일관성, 공개 수집 허용, 사이트맵 및 올바른 HTTP 응답을 권장한다. 이번 설명 정리는 검색 전달 내용을 개선하는 것이며 재수집·색인·순위·스니펫을 보장하지 않는다. 기존 Search Advisor 설정과 소유권 인증은 변경하거나 재수집을 요청하지 않았다.

출처: [네이버 웹 사이트 제작 가이드](https://searchadvisor.naver.com/guide/seo-basic-create). 추가 조사와 계측의 경계는 `ANALYTICS_DETAIL_VIEWS_20261031.md` 참조.

## 미완료와 재개 조건

- 참고 이미지 2장의 공식 Library materialize가 다운로드 후 `os.setxattr` 부재로 실패했다(Windows Python). 원본 파일을 최종 설치할 수 없어 픽셀을 확인하지 못했다. native read도 image asset pointer와 추출 정보만 반환했다. 다운로드 경로를 추측하거나 도우미를 우회하지 않았다.
- 이후 부모 작업이 지원 환경에서 원본 이미지 픽셀을 직접 확인하고 정확한 대상을 전달했다. 이를 근거로 PC 상단 두 번째 열 ‘앞으로 출발편 집중 시간’과 하단 ‘노선·휴일 준비’가 같은 세로선에서 시작하도록 공통 3열 기준을 적용했다. 모바일은 기존 한 열 순서를 유지한다. ‘시간·터미널’ 아래 각 행의 터미널 이름만 T1 레드, T2 블루, 탑승동 틸로 구분하고 행 간격을 12px로 정리했다. 일반 본문·수치·다른 터미널 표시는 변경하지 않았다.
- 긴 비교 기준은 PC에서 한 줄을 유지한다. 320px의 기존 두 열 배치에서 강제 nowrap은 가로 넘침을 만들므로 모바일은 잘리지 않도록 줄바꿈을 유지했다. 모바일 한 줄 요구는 미충족이며, 읽을 수 없을 정도의 축소나 임의의 배치 변경은 하지 않았다.
- GA 실제 보고서 저장·조회와 20시 예약 검증은 부모 작업에서 진행해야 한다. 새로운 수집·인증정보·권한·필터·유료 서비스는 추가하지 않았다. 기존 단일 시험 방문은 재전송하지 않았다.
- main CI 성공 뒤 자동 운영 배포 워크플로가 연결돼 있으므로, 배포 금지 지시에 따라 병합하지 않는다. 원격 draft PR 및 CI 상태를 확인하고 검토 대상으로 남긴다.

원격 저장 장애: 자동 승인 검토가 `codex/date-layout-motion-20261031` 브랜치 push를 ‘외부 저장소 반영에 대한 명시적 사용자 승인 부족’으로 실행 전에 거절했다. push·PR 생성·원격 CI는 수행되지 않았다. 이 거절을 다른 도구로 우회하지 않는다. 적용 가능한 AGENTS.md에는 commit·push·PR 기록 지시가 있지만 자동 검토가 이를 push 승인으로 인정하지 않았으므로 원격 저장은 별도 명시 승인 대기다.
