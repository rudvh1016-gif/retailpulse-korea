# 지원 안내 초안

상태: **게시 전 운영자 승인 필요**. 공개 담당자·이메일·응답시간은 미확인이다. 저장소 커밋 작성자의 개인 이메일을 지원 연락처로 전용하지 않는다. `/support` 경로나 문의 form은 이 PR에서 공개하지 않는다.

## 사용 안내

- 여행 기록은 현재 브라우저·기기에 있습니다. 같은 기기에서도 다른 브라우저나 앱에서는 별도 저장소일 수 있습니다. 브라우저 자료를 지우거나 기기를 바꾸기 전에 `백업 및 복원`에서 JSON을 내려받아 실제 파일을 확인해 주세요.
- 사진은 JPG, PNG 또는 정적 WebP이며 원본 5 MB·20 megapixels 이하를 지원합니다. HEIC/HEIF는 지원하지 않습니다. iPhone 사진은 JPG/PNG로 내보낸 사본을 선택해 주세요. 다른 사진을 읽지 못하면 기존 사진은 유지합니다.
- 기록 삭제: 상세에서 `기록 삭제` → 설명 확인 → 삭제. `취소` 또는 Escape는 변경하지 않습니다. 페이지를 열어 둔 동안 `실행 취소`로 복구하거나 원본 한 건의 `복구 JSON 저장`을 사용할 수 있습니다. 마치기·새로고침·페이지 종료 후에는 메모리 복구 사본을 잊습니다.
- 사진 제거: 상세의 `사진 제거` → 확인. 날짜·공항·메모는 유지합니다. 같은 ID의 이전 JSON은 복원 시 건너뛰므로, 사진을 되돌리려면 페이지의 실행 취소를 먼저 사용하세요. 이미 만든 백업 파일에는 사진이 남아 있을 수 있습니다.
- 실행 취소 충돌: 다른 창에서 기록을 수정하거나 같은 ID를 복원하면 현재 데이터를 덮어쓰지 않습니다. 복구 JSON을 저장한 뒤 최신 기록을 다시 열어 주세요. 복구 JSON을 가져와도 동일 ID는 건너뛰며 자동 덮어쓰지 않습니다.
- 저장 공간 오류: 입력·기존 기록·실행 취소 사본은 유지하며 성공했다고 표시하지 않습니다. 다른 파일/브라우저 공간을 확인한 뒤 다시 시도하세요. 기존 기록을 백업하기 전에 브라우저 저장소를 지우지 마세요. 한도는 300기록·사진 합계 16 MB·JSON 32 MB입니다.
- JSON 복원: 형식·버전·사진 검증 후 추가/동일 ID/중복 숫자를 미리 보여 줍니다. 확인 전에는 저장하지 않습니다. 취소 시 기존 기록은 유지합니다. 변조·지원하지 않는 버전은 거부합니다.
- 공항·지역 정보는 갱신 시각과 실제/예측/관측 범위를 함께 읽어 주세요. 오래되거나 누락된 정보는 운영기관 안내를 함께 확인하세요. 항공편 수를 여객 국적이나 구매로 해석하지 않습니다.

## 문의 흐름 제안

운영자가 승인한 공개 문의 수단을 확보한 뒤 앱 내 도움말과 공개 Support URL에 동일하게 연결한다. 문의에는 앱 버전, 기기/iOS 버전, 문제 발생 순서와 오류 문구를 요청한다. 개인 여행 사진·전체 JSON 백업·민감 메모·인증서·토큰을 기본 첨부로 요구하지 않는다. 화면 공유가 필요하면 개인 메모와 사진을 가린 예시를 사용한다.

문의 수집/처리·보관/삭제 규칙도 개인정보 문서에 포함한다. 실제 승인된 채널·응답 정책이 확인되기 전에는 “24시간 응답” 같은 약속을 게시하지 않는다.
