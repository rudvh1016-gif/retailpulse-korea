## 화면 변경

`/ko/airport` 상단에서 승객용·직원용을 선택한다. 승객용이 기본이며, PR #269의 출국 5단계·선택 환급·Blender 자산 7개를 그대로 재사용한다. 항공편과 시설은 각각 접기 안에서 기존 컴포넌트를 연다.

직원용은 기존 출국·입국·항공편·시설·과거 화면과 수치를 유지한다. 루트 홈의 기존 공항 운영 화면과 서울 진입은 유지한다. 화면 선택은 계정이나 신분 판정이 아니다.

URL의 `audience=passenger|staff`는 터미널·날짜와 함께 유지되며 뒤로가기·앞으로가기·새로고침을 지원한다. 동일 화면의 반복 클릭은 방문 기록을 추가하지 않는다. 출국 가이드의 선택은 화면 전환 동안만 유지하며 전송·개인정보 저장은 하지 않는다. 기존 `section=mystore` 링크는 직원용 매장 화면을 연다.

기존 직원용 E2E의 진입 URL 86곳에 `audience=staff`를 명시했다. 화면 컨테이너가 한 단계 생긴 3개 검사의 선택자와 4개 승객 가이드 검사의 기본 펼침 전제도 갱신했다. 숫자·조건·글리프·배치 검증은 유지한다.

## 승인 범위와 차단

`tests/operational-phase2.test.mjs:117`은 `tests/fixtures/phase2-locks.json`의 보호 파일 해시와 완전 일치를 요구한다. 이번 연결 파일 `app/retailpulse-app.tsx`만 보호 기준과 다르며, 기준을 임의로 바꾸지 않았다.

- 기존 승인 해시: `2ed6669aec005dc9bef2ab6d6f2aa8aa61400becffdb2bde0f4bf349912551c5`
- 이 화면 연결의 검토 대상 해시: `ee93e6e1cb8898dc445f2cb76bb6e96fc7b177f67b278722d4817b10342baa38`
- 필요한 화면 승인: **공항 페이지의 승객용·직원용 선택과 승객용 기본 진입, 기존 출국 가이드 기본 펼침, 직원용 데이터·루트 홈 보존**.

이 승인이 기록되고 해당 변경의 보호 기준 갱신이 허용되기 전까지 draft PR을 유지한다. PR #266/#267 병합 거절이나 PR #274 항공편 timeout 승인 대기를 우회하지 않는다. `app/live-signals.tsx`와 기존 보호 기준, 로그인, 수집·새 API·유료 서비스·배포 설정은 수정하지 않았다. 병합과 배포는 수행하지 않는다.
