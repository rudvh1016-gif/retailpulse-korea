# 공항 중심 승인용 시안

- 경로: `/ko/airport-focus-preview`
- 기준 main: `7c9aef7e7f7d79a143957c777e70f1ee9ac30d72`
- 운영 홈, 기존 메뉴, 서울 URL, 수집기, D1 쓰기, 배포 설정은 변경하지 않는다.
- 승인 전 병합·배포 금지. 이 PR은 검토용 draft이다.

## 구현 범위

기존 AirportGlancePreview에 선택적 React 슬롯 두 개를 추가한다. 슬롯을 전달하지 않는 기존 페이지의 DOM과 수치는 그대로 유지한다. 승인용 페이지는 기존 그림, 필터, 승객 산식, 출발편과 구역 자료를 재사용한다. 공항 현황 탭은 기존 AirportView를 지연 로드한다. 국가별 흐름과 미리 준비는 검증된 스냅샷을 사용하는 신규 표시 컴포넌트다. 서울 기능은 더보기의 기존 URL로 연결한다.

예상 출국객 + 예상 환승객 = 단순 합계라는 기존 표기를 유지한다. 출국객 증감은 같은 출국장 예상 지표의 전월 일평균과 비교한다. 환승 및 단순 합계에는 검증되지 않은 전월비를 붙이지 않는다. 항공편은 기존 준비된 전월 완료일 기준을 우선하고, 전월이 없으면 선택일 이전의 완료일로만 구성된 확보 월 일평균을 사용한다. 포함 기간과 일수를 표시하며 없는 값을 0으로 만들지 않는다.

## 자료 경계

- 기존 홈의 선택일 데이터는 기존 API hook 그대로 사용한다.
- 시안 재현용 E2E는 공개 Production API의 실제 2026-10-19 선택일 응답을 재생한다. 수치, 편수, 차트 모양을 만든 fixture가 아니다.
- 출국장 비교 기준: 2026-09-30 summary의 monthToDate.current, 9월 1–30일 COMPLETE 30/30. 기준 시점과 단위는 표시한다.
- 월 여객 추이: 실제 공식 월 통계 API로 확인한 2026년 4–9월 여섯 나라의 월 출발 여객. 승객 국적이 아니다. 각 sparkline은 독립 축이며 상세에는 월별 원숫자를 제공한다.
- 휴일: 2026-10-20 기준 90일, 60개 국가·지역에서 대표 휴일의 날짜와 적용 범위를 확인한 113개 일정만 사용한다. 각 국가의 전체 90일 일정이나 모든 직장 휴무를 완전히 검증한 뜻은 아니다. 에티오피아는 날짜 확인 중이다. 스냅샷이며 운영 자동 수집 완료를 뜻하지 않는다.
- 휴일과 여객 증감에 인과관계를 붙이거나 국적별 고객·매출 증가를 예측하지 않는다.

## 검증

독립 CI job이 typecheck 및 실제 Chromium 렌더링을 수행하고 360/390/430/1440px 화면을 즉시 artifact로 업로드한다. 기존 full regression CI는 그대로 유지한다. 승인용 화면은 noindex이며 공개 배포하지 않는다.

## 승인 뒤 남는 통합 작업

이 시안은 최종 운영 배포본이 아니다. 승인된 화면을 운영 홈/메뉴로 연결하기, 휴일 검증 국가 확장 및 갱신 절차, 월별 추이의 저장된 공식 이력 조회 연결, 사용자 최종 날짜/범위 검수는 별도 적용 전 확인이 필요하다. 기존 월 API나 수집기를 재구축하지 않는다.
