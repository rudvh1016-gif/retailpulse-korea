## 원인과 수정

이전 `summaryCache`는 날짜별 null/자료 없음/정상 응답을 만료 없이 재사용했다.
서버가 나중에 해당 날짜 자료를 확보해도 같은 탭에는 최초 응답이 남았다.
기존 브라우저 시험에 가짜 응답의 실패/자료 없음 → 정상 자료 흐름을 추가했다.

- 실패·자료 없음은 60초, 부분 자료는 120초, 정상 자료는 300초 후 재확인한다.
- 날짜/월별 진행 중 요청을 공유한다. 숨겨진 탭은 중지하고 복귀 시 만료 여부를
  확인한다. 날짜 재진입도 같은 제한을 적용한다.
- 실패한 갱신은 마지막 정상 자료와 원래 출처 시각을 보존한다. 별도 화면 갱신
  실패 시각을 표시하며, 정상 응답이 오면 그 표시를 해제한다.
- 한국시간 자정에 캐시를 갱신하고 오늘/내일 버튼을 재계산한다. 명시적으로
  선택한 날짜는 유지하며, 늦게 도착한 다른 날짜 응답을 섞지 않는다.
- 자정 직후 조회도 실패하면 마지막 정상 서버 시간과 경과 시간으로 탐색 날짜만
  넘긴다. 숫자/자료 시각은 바꾸지 않으며 날짜 탐색용 추가 요청은 없다.
- 기존 요약 API만 사용한다. 항공편 목록도 기존 flights API를 재사용한다.

## 날짜 자료의 의미

A5는 기존 공식 오늘·내일 수집 경로를 유지한다. 보유한 과거 A5는 과거 예보이며
실제 승객 실적이 아니다. 자료 없음, 부분 시간대, 최근 자료원 수집 오류,
브라우저 갱신 오류를 구분한다. 빈 자료를 공식 미발표라고 단정하지 않는다.

A1은 기존 한 번의 전체 응답에 실제 포함된 유효 미래 날짜를 모두 분리 저장한다.
날짜별 공급자 호출은 추가하지 않는다. +6일 제공을 보장하지 않는다. 모든 페이지의
완결성·중복·총수·날짜·저장 상한을 검증한 정상 수집만 변경/취소를 반영한다.
부분 수집이나 실패는 마지막 정상 일정을 보존한다. 미래 예정편은 actual history에
넣지 않으며, 날짜별 snapshot을 사용한다. 같은 날짜 한 건을 저장하는 동작이 다른
미래 날짜를 지우지 않는다. 완전한 재수집에서는 철회·만료된 일정을 정리한다.

기존 어제/오늘/내일과 날짜 입력을 유지하고 공항에 월별 보유 날짜 선택을 연결했다.
날짜마다 운항 기록·승객 예보·예정편 보유 여부를 표시한다. 기존 21일 선택 제한을
없애고 월별 최대 31일만 조회한다. 자료가 없는 날짜는 그대로 없다고 표시한다.
선택한 날짜의 출처 시각을 표시하며 자료원 전체의 최신 확인 시각과 혼동하지 않는다.
