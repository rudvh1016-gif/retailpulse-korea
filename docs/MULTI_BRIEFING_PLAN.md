# 복수 선택 브리핑

지역·공항 터미널·어제/오늘/내일을 복수 선택하고, 저장한 범위 안에서 브리핑 상단의 버튼으로 전환한다. 역할은 한 가지이며 관심정보는 기존처럼 복수 선택한다. 최소 하나의 선택은 유지한다. 터미널 전체는 개별 터미널과 함께 선택하지 않는다.

1. 기존 version 1 설정과 호환되는 선택 배열 및 검증을 추가한다. 잘못된 값·빈 배열·중복·기본값 불일치는 거부한다.
2. 지역별 가능한 관심정보의 합집합을 제공하고, 실제 브리핑에는 해당 지역의 항목만 보여준다.
3. 4개 언어 선택 문구, 어제 날짜 계산, 전환 UI를 구현한다. 자료가 없는 날짜는 기존과 같이 미제공을 표시한다.
4. 과거 설정·복수 선택 저장·날짜 전환·수정·최소 선택·지역별 항목·GA4 허용값을 테스트한다.
5. 타입·lint·기본/빌드/브라우저 CI를 확인한 뒤 PR을 커밋·푸시하고 main에 일반 병합한다. 운영 배포는 이번 요청에 포함하지 않는다.
