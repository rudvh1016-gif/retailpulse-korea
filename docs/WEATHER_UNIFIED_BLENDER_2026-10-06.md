# 날씨·주변 환경 — 관측과 공식 예보 통합

사용자가 서울의 주변 환경 관측과 날씨 예보를 하나의 대제목으로 합치고 중요한 정보를 각각 Blender 장면으로 보여 달라고 요청했다. PR292의 검증된 구현 위에서 `날씨·주변 환경` 한 제목 아래 현재/최근 관측과 공식 예보를 배치한다. 온도계·습도계/물방울·바람 자루·공기 센서/입자·비구름·해·구름·눈 장면과 기존 실제 DOM 수치를 함께 보여준다.

관측과 예보는 같은 값으로 합치거나 평균내지 않는다. 서울 도시데이터 관측 수치·공식 등급·단위·관측 시각과 최신성 설명, 기상청 기존 예보 수치·발표 시각·대상 시각·안내와 출처는 분리해 보존한다. 새 비구름은 강수확률 정보 항목이며 확률 0%를 실제 비라고 판정하지 않는다. 해·구름·눈은 제공된 conditionCode만으로 선택한다. 최신 관측의 습도·바람이 있으면 해당 예보 필드를 중복하지 않는 기존 규칙, 관측이 오래되면 예보 필드를 보이는 기존 규칙을 그대로 유지한다. 누락을 0으로 바꾸지 않고 기존 PTY-only 누락 상태도 유지한다.
