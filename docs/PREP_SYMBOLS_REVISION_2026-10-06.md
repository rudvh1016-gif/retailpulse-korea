# 영업시간 준비 — 정보 의미에 맞춘 Blender 장면 수정

사용자가 이전 회색 운영 물체가 설명과 어울리지 않는다고 지적했다. 실제 Blender 5.2.1 Cycles로 사람·흐름, 비구름·빗방울, 온도계, 달력·국가, 공연 장면을 새로 만들었다. 서울 전용의 장밋빛·민트·라일락·복숭아 파스텔과 기존 검정 글자·폰트를 사용한다.

`PrepSymbolScene`은 고정 정보 항목 아이콘이다. 강수확률 0%에도 비구름은 항목을 식별하며 실제 비가 내린다는 판단을 뜻하지 않는다. 화면에 이를 짧게 표시한다. 기존 확률, 온도 범위, 혼잡 시간, 행사 수, 공휴일 국가·이름, 출처·한계와 준비할 일은 그대로 DOM에 남는다. 공항은 기존 렌더링을 유지한다.

## 증거와 검증

공개 `https://koretaildata.com/ko/business`의 실제 화면과 공개 요약 API를 2026-10-06 13:17 UTC에 확인했다. 그 데이터를 로컬 수정 화면에 주입했으며 320/390/430/1280px에서 숫자와 원문이 공개 캡처와 정확히 일치했다. 숫자를 제품에 하드코딩하지 않았다. 새 장면 5종과 실제 390px 화면을 픽셀로 확인했다.

기존 행동 E2E 중 4개 언어·320/390/430px·강수확률 0%와 자료 누락 8개를 실행해 모두 통과했다. 지연 로딩, 빈 장식용 alt, 이미지 디코딩, 키보드로 원문 설명 열기·닫기, 검정 글자, 글리프, 가로 넘침과 런타임 오류를 확인했다. 타입·해당 소스 린트·공식 빌드·HTML 42개·준비 및 보호 기준 62개가 통과했다. 기존 검증 완료 이력 뒤 새 main 3개 커밋과 작업 트리를 공식 5개 비밀키 패턴으로 검사했다. 실제 원격 커밋도 별도로 검사한다.

참고 Library `libfile_7b362e32b64c81918ee84c79d39291bd`는 정식 소비 환경 다운로드와 동일 호출 1회 재시도 모두 Windows `os.setxattr` 오류로 실패했다. 소비 경로가 없어 첨부 픽셀을 직접 보았다고 주장하지 않는다. 부모가 확인한 내용과 실제 공개·로컬 화면으로 진행했다. 임의 다운로드·권한 우회는 하지 않았다.

새 검토 파일 4개 PNG와 Blender ZIP의 정식 Library 일괄 저장은 Windows 한국어 경로 인코딩 오류로 `uploads[0].local_path must name a file`, UTF-8을 명시한 동일 배치 1회 재시도는 `stdin must contain valid JSON`으로 실패했다. 새 Library ID는 발급되지 않았다. 다른 저장 방식으로 우회하거나 추가 재시도하지 않았다. 로컬 검토 파일과 원격 코드·자산은 보존한다.
