## 소비 비교의 실제 단위

[서울시 공식 매뉴얼 V8.5 36쪽](https://data.seoul.go.kr/SeoulRtd/downloads/%EC%8B%A4%EC%8B%9C%EA%B0%84_%EB%8F%84%EC%8B%9C%EB%8D%B0%EC%9D%B4%ED%84%B0_%EB%A7%A4%EB%89%B4%EC%96%BC.pdf): 가맹점 소비를 10분 간격으로 집계하며 10:10–10:20 결제값이 집계 후 10:35에 제공되는 예를 든다. 일 누적값이나 단순 10분 갱신 주기로 해석하지 않는다. CMRCL_TIME에 별도 구간 시작 필드가 없어 정확한 시작·끝 시각을 만들어 내지 않는다.

월 비교는 같은 날짜번호·시간대에서 각 시간 안의 공개 10분 기록을 평균낸 뒤 시간별 평균을 동일한 비중으로 평균낸다. 80/121은 **날짜×시간대 묶음 수**이며 10분 기록 수·연속 시간·일평균이 아니다. 실제 날짜·공통 시간대·원본 관측 수를 표시한다. 업종의 비공개·누락 값 때문에 포함 시간은 다를 수 있다. 금액 최소·최대 범위는 금액이 함께 공개된 별도 시간대·관측 분모로 계산하므로 결제 분모와 구분한다. 월 매출 총액·매장 매출·외국인 매출로 표시하지 않는다.

## 공통 시각 규칙

기존 KORETAIL Sans Variable/Pretendard를 유지한다. 흰 바탕, 기존 ink / muted / line 토큰, 제목=type-title, 핵심 숫자=type-key, 본문=type-body, 보조=type-secondary를 공유한다. 강한 굵기는 제목과 핵심 숫자에 사용한다. 시간 기준은 회색 바탕의 같은 크기 선택 항목이며 외곽선·파란 밑줄·별도 그림은 사용하지 않는다. 승인 D 항공편 3D 모형은 유지한다.

출국장 대기 모형은 T1 출국장 내부 동·서 / T2 1A–2D를 표시하는 개념도다. 항공편의 터미널 전체 동·서·중앙과 분리한다. 공식 그림을 복사하거나 공식 좌표라고 주장하지 않는다. 0분·미제공으로 운영 종료나 원활을 추론하지 않는다. 종료는 원자료의 명시값만 쓰고 오래된 종료 기록은 현재 종료로 강조하지 않는다.
