## 후속 구현과 검증 기록

월 선택당 읽기를 최대 3회로 제한하고 이전 요청을 취소한다. 응답 월·지역과 자료 내부 월·지역을 확인한다. 실패 시 정확히 같은 선택의 마지막 정상 집계만 보존하고 기준일·계산시각을 표시한다. 지역이나 월이 다른 늦은 응답은 덮어쓰지 못한다. 수동 재확인은 자동 확인이 끝난 뒤 작은 텍스트 버튼으로 제공한다.

소비 화면에는 업종별 실제 포함 날짜와 날짜별 시간대를 표시한다. 전체 시간대와 금액의 별도 관측 분모를 펼칠 수 있다. 기존 집계값과 동일한 결과로 재계산이 확인될 때만 보존된 시간 목록을 공개 응답에 더한다. 최초·최종 저장시각 범위는 비연속이라고 명시한다. 기존 결제 평균·변화율·금액 평균의 계산을 바꾸지 않는다.

시간 선택은 같은 크기의 회색 분할 선택으로 바꾸고 0편인 미확인 항목만 감춘다. 실제 양수·미확인과 모든 시간 선택 기능, 날짜·범위·목적지·게이트 상세를 유지한다. 공통 역할 토큰은 새 scoped CSS에서 기존 글꼴·굵기·색상 값을 참조하며 보호된 globals.css와 폰트 파일은 바꾸지 않았다.
